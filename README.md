# Borrower Copilot

Step 1 creates the React + Vite shell, Tailwind design tokens, phase-based navigation, in-memory state, reusable UI components, and tests.

## Run locally

```bash
npm install
npm run dev
npm run lint
npm run test
npm run build
```

## Current boundary

This foundation intentionally does not include loan calculations, questionnaire branching, verdict logic, APR, FOIR, persistence, login, analytics, or backend calls. Answers are held only in React memory while the page is open.
